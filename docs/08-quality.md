# 质量准则：内存、性能与使用体验

> 这是实现期的评审依据，不是营销文案。预算先作为目标，M1 起记录基线，M3 做专项优化；
> 任何「先做出来再优化」都不能违反这里的结构性约束。

## 1. 预算

| 指标 | 目标 | 测量方式 |
| --- | --- | --- |
| 冷启动到可交互 | ≤ 2.5s（内置内核、已有配置、无首次 Geo 下载） | 启动阶段打点 |
| 托盘唤出窗口 | ≤ 300ms | 打点 |
| 页面切换（数据已缓存） | ≤ 100ms | 打点 + 帧统计 |
| 流式刷新 | UI 合并到 ≤ 10Hz；表格滚动 ≥ 30fps | MyGo 性能文档 + 真机 |
| 配置应用（无下载） | 典型 ≤ 1s；失败回滚 ≤ 2s | 管线打点 |
| 搜索/过滤 1000 行 | ≤ 50ms | 基准测试 |
| 磁盘写入 | 设置去抖 500ms；流量 1 次/分钟 | 代码审查 + 日志 |
| 内存 | 不设硬上限；每个里程碑基线回归 ≤ 10% | 真机采样（空闲/100 连接/1000 规则） |

内存数字在标准模式、轻量模式两种形态下分别记录；不拿一种形态的数字代表全部。

## 2. 内存

### 2.1 形态与代价

| 形态 | 进程 | 适用 | 代价 |
| --- | --- | --- | --- |
| 标准（默认） | GUI（内嵌内核） | 日常 | 最低进程数；内核随应用版本 |
| 轻量模式 | Agent（内核 + 托盘）+ 按需 GUI | 关窗后保留代理 | 窗口打开时两进程；无 Skia 的 Agent 更省 |

选择权给用户，但设置页必须写清代价；不把「轻量」宣传成「零内存」。

### 2.2 有界数据

- 日志：环形缓冲 5000 行 / 8MB；落盘按日轮转，默认 7 天、单文件 16MB。
- 连接：只保留当前快照；不累积历史；暂停时仍只保留最新一帧。
- 速率曲线：60 点；流量历史按分钟落盘，不在内存留全量。
- 规则：只保留当前列表与索引；分页渲染，不复制整表。
- 图标/图片：LRU，上限按数量与总字节双重限制。
- 剪辑板/诊断：导出后释放；不缓存大字符串。

### 2.3 懒加载与释放

- 页面只在可见时构建数据订阅；离开页面取消订阅、停计时器。
- 表格/列表只渲染可见行（MyGo `Table`/`List` 已虚拟化）；不要为排序复制一份完整行对象。
- 编辑器/差异视图只在打开时创建；关闭后释放 buffer。
- WebView 只在面板页创建；离开时销毁，保留 URL 与滚动位置。
- 窗口销毁时释放页面级缓存、图片、图表数据；保留必要的应用状态（当前页、筛选条件可重建）。
- 系统材质与玻璃不在不可见窗口上持续刷新。

### 2.4 并发与泄漏

- 每条流一个归属 goroutine；内核停止/切换时 `context` 取消并等待退出。
- 每个页面的定时器在离开时停止；禁止 `time.Ticker` 无主。
- 测速/下载任务可取消；取消后连接关闭、临时选择恢复。
- 不在 view 内启动 goroutine 后捕获 `ui.Element`；只捕获取自 `c.Services()` 的服务。
- 从 goroutine 重绘用 `win.Update`，合并到 ≤10Hz；不逐帧调用。

### 2.5 分配与 JSON

- 复用缓冲；流解析按行解码，不把整包拼成字符串。
- 避免在绘制路径做 map 查找 + 分配；预计算列/行索引。
- 不在每帧创建格式化器；数字/字节格式化按需缓存。
- 大 YAML 只在保存/预览时解析；不常驻 AST。

### 2.6 测量

- `runtime/pprof`（heap、goroutine、block）与 `go test -bench`。
- 真机采样三个场景：空闲、100 连接、1000 规则 + 10k 规则提供者。
- 每次里程碑记录基线；回归超过 10% 必须解释或修复。
- 不凭肉眼判断「卡」；用帧时间与 CPU profile。

## 3. 性能

### 3.1 启动

顺序：单实例锁 → 路径/迁移 → 设置/状态 → 内核启动 → 首帧 → 流 → 延迟任务。

- 首帧不等待订阅同步、Geo 下载、更新检查。
- 设置/索引读取失败不阻塞启动；隔离损坏文件，用默认值继续。
- 内核启动与首帧并行；首帧显示骨架与「正在启动内核」。
- 恢复窗口几何/页面状态不触发额外磁盘扫描。

### 3.2 交互

- 点击反馈 < 100ms；超过 150ms 显示骨架/进度；超过 500ms 必须可取消。
- 搜索去抖 150ms；过滤在内存完成；大列表用索引。
- 开关操作先置「进行中」，读回真实状态后落定；不做乐观假状态。
- 页面切换不重建全局状态；只重建该页数据。
- 避免布局抖动：固定行高/列宽，长文本省略 + tooltip。

### 3.3 流与网络

- `/traffic`、`/connections`、`/logs` 各一条连接；断线指数退避，不并发重连。
- 页面不可见时降低消费频率（连接 5s、日志仍接收但少合并）。
- 订阅下载 30s 超时、并发 ≤ 2；测速并发 ≤ 1；延迟测试并发 ≤ 16。
- 更新检查每天一次；GitHub 请求带 ETag；失败不重试风暴。
- 所有请求 `Proxy: nil`（订阅/更新/Geo），避免环路。

### 3.4 磁盘

- 设置/状态写去抖 500ms；原子 rename。
- 流量每分钟追加；不 fsync 每行；按月压缩。
- 日志异步写；轮转与清理在空闲时执行。
- 备份/导出在后台任务，显示进度，可取消。

### 3.5 视觉成本

- 玻璃 pane ≤ 6/屏、Group ≤ 8；工作卡不透明度是唯一入口；实色预设关闭全部材质。
- 系统材质只用于 Ground；数据表/日志/编辑器/设置块用实色画布。
- 悬浮窗 1s 刷新；失焦降频。
- 图表只画可视区；不每帧重算全量数据。
- 图标按 DPI 缓存；不每次从磁盘解码。

## 4. 使用体验与人体工学

### 4.1 原则

1. **一个屏幕一个主行动**：导入、启用、开启代理，各自只有一个主按钮。
2. **状态即事实**：开关读系统/内核真实值；不确定时显示「检查中」，不猜测。
3. **减少决策**：默认值合理；高级项收进分组；危险项二次确认。
4. **随时可退**：长任务可取消；配置切换失败回滚；关闭窗口不丢未保存内容（先询问）。
5. **键盘可达**：所有主路径不依赖鼠标；焦点可见；快捷键可发现（菜单/提示）。
6. **平台惯例优先**：菜单栏、托盘、窗口按钮、快捷键（Cmd/Ctrl）按平台。
7. **文案可执行**：错误说清「发生了什么、为什么、下一步」；不用「未知错误」。

### 4.2 密度与命中区域

- 正文 14px，行高 36px（紧凑 28px）；表格行整行可点。
- 可点击目标 ≥ 28×28（紧凑表格内的图标按钮 ≥ 24×24，且行本身可点）。
- 表单标签与输入同一行或紧邻；错误紧贴字段，不集中到页尾。
- 数字列右对齐、等宽；单位与数值同一行，不换行。

### 4.3 反馈与状态

- 操作后 100ms 内必须有视觉反馈；结果用行内状态/Toast，不用阻塞对话框。
- 加载 >150ms 显示骨架；>500ms 显示进度与取消；>5s 显示「仍在进行」。
- 空状态：一句说明 + 一个主行动；不显示假数据/空图表。
- 错误条：可展开详情、复制、关闭；同类错误合并计数。
- 成功但无变化：说明「已是最新」；不弹空洞的「成功」。

### 4.4 危险操作

- 删除配置、重置数据、关闭 TUN、切换内核来源：二次确认 + 说明影响。
- 不可逆操作（清空日志/删除备份）明确写「不可恢复」。
- 可撤销的（关闭连接）不做确认，但显示结果。
- 退出时若系统代理/TUN 开启，说明将被关闭；不静默断网。

### 4.5 键盘与搜索

- `Ctrl/Cmd+1..6` 主页面；`/` 或 `Ctrl/Cmd+F` 搜索；`Esc` 关闭抽屉；`Space` 暂停流。
- 搜索框自动聚焦、清除按钮、空结果说明；搜索词不跨页污染。
- 表格支持方向键移动、Enter 打开详情、右键菜单；列头可键盘排序。
- 所有图标按钮有可读标签（tooltip + 无障碍名称）。

### 4.6 测速体验

- 区分「延迟测试」（毫秒）与「网速测试」（Mbps），文案不混用。
- 测速前显示将消耗流量、目标节点、测试时长；需用户主动开始。
- 过程中显示实时速率、已用流量、已用时间、取消按钮。
- 指定节点测速只对 select 组临时切换，结束恢复原选择；失败也恢复。
- 结果保留在本次会话；不自动上传、不写入订阅流量统计之外的地方。
- 节点太慢时可一键「测当前节点」，不需要先改全局选择。

### 4.7 轻量模式体验

- 设置项名称：「关闭窗口后释放界面内存（保留托盘与内核）」。
- 开启前说明：窗口关闭后由后台进程继续代理；再次打开会连接到后台内核。
- 轻量模式下窗口打开时，状态条显示「内核在后台」；避免用户以为有两份配置。
- 切换模式会重启内核，明确提示「连接会短暂中断」。
- 托盘菜单始终有「显示窗口 / 重启内核 / 转发模式 / 系统代理 / TUN / 退出」。
- Windows/macOS：左键打开窗口、右键菜单；Linux：点击打开菜单（AppIndicator 限制）。

### 4.8 国际化与无障碍

- 所有文案走 i18n；不拼接句子；复数与日期用 locale 规则。
- 屏幕阅读器依赖真实控件语义；不用 Box 模拟按钮。
- 对比度：正文 ≥ 4.5:1；状态不只靠颜色。
- 尊重 ReduceTransparency / HighContrast / ReduceMotion / TextScale。
- 200% 缩放下不截断；长语言（英文）不溢出按钮。

## 5. 评审清单（每个 PR）

- [ ] 新增数据有上限与释放路径（日志/连接/图片/缓存）。
- [ ] 新增 goroutine/定时器有取消与归属。
- [ ] 不在 view 内做 IO/锁等待；重绘合并到 ≤10Hz。
- [ ] 大列表/表格未复制整表；搜索/排序有基准或理由。
- [ ] 失败路径可回滚，错误文案含下一步动作。
- [ ] 开关读回真实状态；没有乐观假状态。
- [ ] 材质/玻璃用量与降级路径符合 `09-appearance.md`；guard 测试通过。
- [ ] 中英文案齐全；键盘可达；对比度达标。
- [ ] 里程碑基线未回归超过 10%，或已记录原因。

## 6. 反模式

- 每帧分配、每帧格式化、每帧读磁盘。
- 已有流却用轮询；多个页面各自开一条流。
- 同一份数据在 store、页面、组件各存一份。
- 在 view 里弹阻塞对话框或等待网络。
- 无界日志/连接/历史；只增不减的缓存。
- 给长文本/数据表铺玻璃、在每行上加模糊。
- 用玻璃伪装桌面磨砂（Linux/Win10）。
- 乐观切换开关，失败后静默回弹。
- 把错误只写进日志，界面显示「失败」。
- 启动时自动测速、自动下载 Geo、自动检查更新并阻塞首帧。
- 静默改用户配置或系统设置。
