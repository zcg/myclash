# Roadmap

> 功能全集见 `docs/01-prd.md`，架构见 `docs/03-architecture.md`。这里只排顺序与出口条件。

## 交付原则

1. **每个里程碑结束时，三端都能安装并跑通该阶段的演示脚本。**
2. **功能完成 = 代码 + 测试 + 中英文案 + 三端验收记录**，缺一项不算完成。
3. **先纵向切片，再横向铺开**：先让「启动 → 导入订阅 → 启用 → 系统代理 → 概览有速率」这条链在三端跑通，再补页面。
4. 任何偏离 ADR 的实现，先改 ADR，再写代码。

## M1「日常可用」

### 工作流 A：工程基础

- 初始化 Git 仓库、`.gitignore`、CI（Windows/macOS/Linux 三 runner）。
- 安全基线：`route.SetEmbedMode(true)`、runtime config 脱敏、Controller 仅 loopback（见 07）。
- 用 `06-parity.md` 建一张勾选表：每完成一项功能勾一项，发版前逐项核对。
- `mygo.json` 元数据、图标、版本号；`mygo keygen` 生成更新密钥（私钥进 CI secret）。
- 路径与便携检测、设置 schema + 迁移、i18n 骨架、窗口外壳。
- 外观：预设（混合/原生/液态玻璃/实色）、模糊档位、工作卡不透明度、明暗跟随、强调色、密度、缩放；
  Lucide 图标按需内嵌；亚克力组件层 + guard/洋红测试。
- 单实例、托盘（左键窗口/右键菜单；Linux 点击菜单）、开机启动、关窗行为、退出清理框架。

### 工作流 B：内核

- `core.Host` 接口 + Embedded 实现（`hub.Parse` / `executor.Shutdown`）。
- 标准模式（单进程）+ 重启内核（bundled）+ 内核页只读信息。
- REST 客户端：版本、配置、代理、规则、连接、日志、流量、内存、提供者、DNS、缓存。
- 流消费者：traffic / memory / connections / logs；断线重连与快照发布。
- 端口占用检测与回退；错误模型与错误条。

### 工作流 C：配置

- Profile 库（`profiles.yaml` + 文件）、本地导入、订阅添加/更新、`subscription-userinfo` 解析。
- 合并覆写（深合并/前插后插/删除）、Runtime 生成、mihomo 校验、原子切换、Last Known Good。
- YAML 编辑器（`CodeEditor`）与行号错误定位。

### 工作流 D：页面

- 外壳：侧栏 + 路由 + 底部状态条 + 工具条规范。
- 概览、代理、配置、连接、规则、日志六个主页面。
- 设置页：常规、外观、内核、数据、关于；DNS 设置；资源页只读列表；内核页（只读 + 重启）。

### 工作流 E：系统代理

- Windows / macOS / Linux 三套后端 + 快照/恢复 + 绕过列表校验。
- 启动自检修复残留；端口变更跟随；状态读回系统真实值。

### 工作流 F：打包

- 三端构建脚本；Windows `setup.exe` + zip；macOS `.app`/dmg（先不公证）；Linux tar.gz/deb/rpm。
- 许可页与第三方声明。

### M1 出口

- PRD §8 的 M1 清单全部通过。
- 三端安装包可安装，演示脚本三端跑通。
- 配置切换失败回滚有自动化测试；中英无缺键。

## M2「网络与高级」

### 顺序

1. **Privileged Host**：握手、超时、清理、失败回弹（Windows UAC / macOS 授权 / Linux pkexec）。
2. **TUN**：三端开启/关闭、DNS 恢复、诊断卡片、与系统代理互斥、冲突检测（Windows Hyper-V/WSL、Linux docker0）。
3. **PAC**：本机 PAC 服务、模板、平台能力隐藏、原值恢复。
4. **覆写**：脚本覆写（goja 沙箱）、三段预览、`DiffViewer`、模板与重置。
5. **高级只读**：连接详情/导出、节点详情/固定、规则提供者预览、规则禁用。
6. **系统集成**：托盘动态图标、热键、通知、UWP 工具（Windows）、更新检查与安装。
7. **数据**：备份/恢复、DNS 编辑页、嗅探页、Geo 更新。
8. **面板**：静态资源下载/校验、`ui.WebView` 注入、缺失运行时的指引。
9. **安全**：面板 secret 策略、脚本沙箱、订阅大小/路径限制，跑 07 的对应验收项。
10. **内核页**：版本/路径/宿主/启动时间/日志/重启；发布说明写清 mihomo 版本。
11. **网速测试**：当前节点/指定节点、实时 Mbps/TTFB/抖动、取消与选择恢复。
12. **命令面板**：`Ctrl/Cmd+K` 跳页/切模式/选节点/重启内核。

### M2 出口

- TUN 三端可用，授权拒绝路径有明确提示且状态不脏。
- PAC 在 Windows/macOS/GNOME 生效；不支持的桌面隐藏入口。
- 脚本覆写有超时与沙箱测试；更新验签失败拒绝安装。
- 网速测试在 select 组与非 select 组行为符合预期；命令面板可键盘完成。
- 三端安装包升级路径演练通过。

## M3「完整与打磨」

1. **轻量模式（Agent）**：控制 socket、附着/脱离、托盘归属、状态单写者、关窗释放 GUI、再次打开。
2. 流量历史（采样、聚合、图表、保留策略）与悬浮窗。
3. WebDAV 同步（冲突策略、凭据存系统密钥库）。
4. 解锁测试、深链/文件关联、便携模式、诊断包脱敏导出。
5. 持久化提权助手：Windows 服务、macOS LaunchDaemon、Linux systemd + polkit；安装/卸载可逆。
6. TUN 与轻量模式的组合验证：Agent 持有内核时切 TUN，停止/恢复顺序正确。
7. 可访问性与键盘走查、200% 缩放、减少动画/提高对比度。
8. 性能与体积专项（此时才做）：启动、内存、二进制、系统材质与玻璃开销；三形态内存基线。
9. 发布工程：代码签名、macOS 公证、更新通道、回滚演练、三端干净虚拟机验收。
10. 安全收尾：跑完 `07-security.md` 的验收测试；第三方许可清单与「关于」页一致。

### M3 出口

- PRD 全表功能通过；平台矩阵中每一项都有验收记录。
- 发布流水线一键产出三端资产与校验和；上一版本可回滚。
- 无 P0/P1 缺陷；崩溃与错误日志无敏感信息。

## 风险闸门

| 闸门 | 触发条件 | 处理 |
| --- | --- | --- |
| macOS 提权 | M2 的 `osascript` 方案在硬化运行时/公证后失败 | 提前到 M3 的 LaunchDaemon，M2 用「仅提示需要 TUN 助手」降级 |
| Linux 桌面兼容 | 目标用户不在 GNOME/KDE | 隐藏系统代理入口，文档引导 TUN；不做更多桌面后端 |
| WebView 运行时缺失 | Linux 无 WebKitGTK 4.1 | 面板页给出安装命令；不阻塞主功能 |
| 内核升级破坏注入字段 | 黄金测试或冒烟失败 | 锁版本，修复前不升级 |
| 更新密钥丢失 | CI secret 不可用 | 保留离线备份；密钥轮换需新版本内置新公钥 |
| 轻量模式状态双写 | GUI 与 Agent 同时改状态/托盘 | 单写者（内核所有者）+ 控制协议 + 单实例锁 |
| 材质/玻璃性能 | 低端机或远程桌面掉帧 | 切实色/原生预设；减少 pane；不逐项加模糊 |
| 亚克力资产 API 漂移 | MyGo 升级后编译失败 | 锁 MyGo 版本；入库后跑自带测试与 guard |

## 任务完成定义（DoD）

- 行为有测试（单测/黄金/`ui.NewTester`/集成之一）。
- 三端行为一致；平台专属项有标注与隐藏逻辑。
- 外观改动跑过 guard 测试与洋红压力截图；玻璃/材质用法符合 09。
- 中英文案齐全；错误文案含下一步动作。
- 无新增 `TODO`/`FIXME` 未记录；有则开 issue。
- 涉及决策的改动同步 ADR 或 PRD；新引用外部资料先核对版本并记入 11。
- 代码组织、依赖方向、命名与 UI/测试规范符合 `13-code-style.md`。
