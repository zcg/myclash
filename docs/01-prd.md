# PRD：myclash

> 术语以 `GLOSSARY.md` 为准，决策以 `docs/adr/` 为准。本文回答「做什么、做到什么程度、怎么验收」。

## 1. 一句话

Windows、macOS、Linux 三端同等支持、默认单进程、亚克力与玻璃质感的 mihomo 客户端：日常操作在 6 个主页面内完成，高级网络能力收在分组页面里，功能覆盖 Clash Verge Rev 与 Clash Party 的并集（例外见 ADR-0006）。

## 2. 目标

1. **装好即用**：首次启动 3 步内完成「导入订阅 → 启用配置 → 开启系统代理」。
2. **状态可见**：任何时刻都能从界面读出内核是否在跑、流量走了哪条规则、为什么。
3. **失败可恢复**：配置切换、内核崩溃、系统代理残留，都有明确且一键的恢复路径。
4. **桌面级手感**：原生控件、键盘可达、深浅色、系统材质/窗口内玻璃/实色三种观感都成立。
5. **默认单进程**：标准模式下不开 TUN 时只有一个进程；轻量模式按需增加 Agent 进程，并在设置中说明代价。
6. **三端一致**：同一功能在三端都存在且行为一致；平台无法等价的项显式标注并在其他端隐藏，不留死按钮。

## 3. 非目标

见 `docs/adr/0006-scope-exclusions.md`：不内置 Sub-Store 后端、不做 MCP、不做多内核热切换、不做 Tailscale 引导登录、不做移动端。

## 4. 用户与场景

| 用户 | 关心什么 | 典型动作 |
| --- | --- | --- |
| 日常用户 | 能不能上网、快不快 | 开机静默启动、托盘切转发模式、看速率、换节点 |
| 折腾用户 | 可控性 | 多订阅、覆写、规则/提供者、DNS、TUN、看日志 |
| 临时/远程 | 干净与可携带 | 便携模式、导入导出、诊断包 |

**S1 首次使用**：安装 → 启动 → 粘贴订阅 URL → 自动命名并下载 → 选中并启用 → 打开系统代理 → 概览显示速率与连接数。
**S2 节点变慢**：代理页搜索组 → 组内测速 → 选最低延迟 → 概览速率恢复；选择在重启后保留。
**S3 订阅到期**：配置页卡片显示剩余流量与到期日；到期前 3 天概览提示条出现。
**S4 需要全局**：网络 → TUN 开启 → UAC 确认 → 内核切到提权宿主 → 诊断显示网卡与路由就绪；关闭后回到单进程。
**S5 配置改坏**：编辑 YAML 引入非法字段 → 保存时校验失败并定位行 → 选择「仍然保存」不生效于运行；启用失败自动回 Last Known Good。

## 5. 产品原则

1. **单一事实来源**：开关与状态读内核/系统实际值，UI 不猜测、不乐观显示。
2. **原子切换**：配置变更要么完整生效，要么回滚，不留半生效状态。
3. **默认安全**：Controller 只绑 loopback；不默认 `allow-lan`；不改系统设置除非用户显式开启。
4. **退出干净**：退出时关闭系统代理、停止内核、恢复 DNS 与防火墙改动。
5. **密度优先**：每屏一个主行动；表格与日志保持实色底，系统材质与玻璃只做容器。

## 6. 功能需求

优先级：M1 首个可用版本，M2 网络与高级能力，M3 统计、同步与打磨。表中「M1/M2」表示拆开的两段（如系统代理 M1、TUN M2）。「验收要点」是测试用例的最小集。

## 7. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 启动 | 冷启动到可交互 ≤ 2.5s（含内核）；托盘唤出窗口 ≤ 300ms |
| 平台一致性 | 三端功能矩阵一致；平台专属项在 UI 中标注并隐藏于其他端；三端 CI 全绿才可发版 |
| 质量准则 | 按 `08-quality.md` 的预算与评审清单执行；不新增反模式 |
| 外观 | 按 `09-appearance.md`：系统材质、窗口内玻璃、亚克力纪律三者并存；明暗/辅助功能跟随系统 |
| 帧率 | 滚动与流式更新目标 60fps，下限 30fps；UI 线程不做网络与磁盘 |
| 内存 | 当前阶段只观测不设门槛；连接表与日志必须虚拟化/环形缓冲，不随量线性增长 |
| 网络 | 所有请求可取消；订阅下载 30s 超时；测速并发 ≤ 16 |
| 安全 | Controller 仅 loopback 且强制 secret；提权进程校验 parent PID + 一次性 token；密钥进 Credential Manager |
| 可访问性 | 键盘可达全部主操作；焦点可见；正文对比度 ≥ 4.5:1；尊重「减少动画」「提高对比度」 |

## 11. 实现细节（已定，变更不需要 ADR）

1. 持久化提权助手（Windows 服务 / macOS LaunchDaemon / Linux systemd + polkit）统一在 M3 交付；M2 使用一次性授权。
2. PAC 默认模板：私有网段与 localhost 直连，其余走代理；不按 Profile 生成例外，用户可在编辑器里改。
3. 流量历史：采样粒度 1 分钟，默认保留 90 天；按 Profile 保留每日汇总。
4. 解锁测试：目标清单内置为可编辑 JSON（默认 6 项），判定按「可用 / 仅自制 / IP 受限 / 失败」四档，阈值随目标配置。
5. Web 面板：默认 metacubexd，允许用户填自定义面板 URL；自定义远程面板默认不获得 secret。
6. 默认订阅 UA 为 `clash-verge/v2.4.2`（兼容优先，可在每个订阅覆盖）；不自称 mihomo 版本。
7. 默认混合端口 7890，Controller 9090；冲突时自动建议 7891/9091 并让用户确认。
8. 转发模式是运行时状态（`tunnel.SetMode`），不因切模式重生成整份配置；重启后以设置中的默认模式启动。
9. 无遥测；更新检查只发 HTTPS 请求，不带用户标识。
10. 默认 `run_mode: standard`（单进程）；轻量模式需用户显式开启，切换会重启内核。
11. 内核只做 bundled，随应用更新；不提供独立内核下载/切换（ADR-0012）。
12. 网速测试默认只测当前节点；指定节点仅在 select 组临时切换，结束恢复；默认端点 Cloudflare，可替换。
13. 第三方 UI 组件库不作为运行时依赖；图标用 Lucide 按需内嵌（ADR-0010）。
14. 外观默认「液态玻璃」预设：系统材质优先 + 玻璃卡；工作卡不透明度 80%，可调到 0%。
