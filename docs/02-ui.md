# 界面设计：信息架构、亚克力规范与页面规格

> 依赖 `GLOSSARY.md` 的术语。控件选择遵循 `mygo-components` 的对账方法；外观以 `09-appearance.md` 为准：
> 系统材质、窗口内玻璃、亚克力纪律三者并存。

## 1. 设计立场

- **原生优先**：主界面全部用 MyGo 原生控件，不用 WebView 拼界面。
- **密度优先**：桌面工具，不是营销页。默认 28px 列表行高，信息一屏尽量多。
- **材质是容器，不是内容**：窗口底用系统材质（能透桌面）或窗口内玻璃（只透应用内容）；
  工作卡半透明，卡片上的控件只用洗色；表格、日志、编辑器、设置块放在实色 Code/Popover 画布上。
- **状态即事实**：开关、转发模式、节点选择都读内核/系统真实值，加载中显示骨架而不是猜一个值。
- **三端一致**：同一页面在三端结构相同；平台专属项标注并隐藏，不出现灰死的按钮。

## 2. 窗口与外壳

| 项 | 规格 |
| --- | --- |
| 默认尺寸 | 1180 × 760 |
| 最小尺寸 | 940 × 600 |
| 标题栏 | `TitleBarHiddenInset`（acrylic 外壳）；`c.TitleBar()` 预留窗口控件区 |
| macOS | 保留 traffic lights，`TrafficLightPosition` 与侧栏对齐 |
| Windows | 使用系统窗口控件区；窗口圆角与阴影交给系统 |
| Linux | 由窗口管理器绘制边框；不假设圆角 |
| 背景 | `acrylic.Window`：透明 + 首帧底色 + `Vibrancy`；根铺 `acrylic.Ground`（有材质铺 65% 薄纱，否则实铺） |
| 缩放 | 支持 100%–125%；表格列宽按 DIP 计算，图标随缩放 |

窗口开关行为：关闭 = 最小化到托盘（默认，可改为退出）；托盘退出才真正退出并清理系统代理/TUN。

窗口清单：

| 窗口 | 数量 | 位置/尺寸记忆 | 说明 |
| --- | --- | --- | --- |
| 主窗口 | 1 | `StateKey: main` | 侧栏 + 内容；多显示器时限制在可见区域 |
| 悬浮窗 | 0..1 | `StateKey: floating` | 无边框、置顶、整窗一张 Card；可叠玻璃材质；不抢焦点 |
| Web 面板 | 0..1 | `StateKey: panel` | 独立窗口，随主窗口退出 |
| 抽屉/对话框 | 临时 | 不记忆 | 不独立成窗口 |

平台外壳：macOS 提供标准应用菜单（关于/设置/退出）与 traffic lights；Windows/Linux 使用隐藏标题栏时保留系统按钮，
若窗口管理器不支持隐藏标题栏则回退到系统标题栏（启动时探测，不静默错位）。
Linux 无原生材质：Ground 实铺，设置页标注「当前系统不支持窗口材质」，不伪造桌面磨砂。

## 5. 视觉 Token

**颜色**（以 `acrylic.Palette` 为准，不写死）：

- **层**：`Ground` / `Card` / `Popover` / `Modal` / `Code`（不透明，只许当一层的底）。
- **洗色**：`WashHover` / `WashChip` / `WashSelected` / `WashKbd`（半透明，只许当控件/条带的底）。
- **线**：`Hairline` / `HairlineStrong` / `HairlineTertiary`（1px）。
- **墨**：`Ink` / `InkMuted` / `InkSubtle` / `InkTertiary`。
- **强调**：`Accent` / `AccentHover` / `AccentPressed` / `AccentText`，`Selection`、`Focus`。
- **语义**：`Success`（连接正常/低延迟）、`Warning`（订阅将到期）、`Danger`（错误/高延迟）。
- **速率色**：上行/下行各一支，图例始终显示；不用透明度区分状态。

**字体**：系统 UI 字体；等宽用于日志、YAML、IP、端口。

| 层级 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| 页面标题 | 22 / Semibold | 每页一个 |
| 区块标题 | 15 / Semibold | 卡片组 |
| 正文 | 13 / Regular | 默认 |
| 次要 | 12 / Regular | 说明、时间 |
| 标注 | 11 / Regular | 徽标、表头 |
| 按钮 | 12.5 / Medium | 控件 |
| 数值 | 20–28 / Semibold + Tabular | 速率、延迟 |

**动效**（见 `mygo-motion`）：

| 场景 | 时长 / 曲线 |
| --- | --- |
| 洗色/文字颜色 | 120ms / `ui.EaseInOut` |
| 面板展开、抽屉 | 180ms / `ui.Snappy` |
| 数值变化 | 160ms 插值，不逐帧跳动 |
| Toast | 220ms 进入，停留 3s |
| 页面切换 | 不做整页动画，避免干扰 |

尊重「减少动画」：关闭位移与缩放，仅保留透明度变化。

## 6. 材质与预设

系统材质（透桌面）与窗口内玻璃（透应用内容）是两个层次，可以同时使用；平台映射与限制见
[`09-appearance.md`](./09-appearance.md)。

| 预设 | Ground | Card | 工具条/浮层 |
| --- | --- | --- | --- |
| **液态玻璃（默认）** | 系统材质（Win11 Acrylic / macOS Liquid Glass） | 半透明色 0–100% | 玻璃浮层 |
| **透明** | 不铺底、不挂材质，直接显示桌面 | 半透明色 0–100% | 玻璃浮层 |
| **实色** | 实色 | 实色 | 实色 |

| 轴 | 选项 | 默认 |
| --- | --- | --- |
| 工作卡不透明度 | 0%–100% | 80% |
| 玻璃强度 clarity | 固定 0.45（不暴露） | 0.45 |
| 密度 | 舒适 / 紧凑 | 舒适 |
| 明暗 / 强调色 / 缩放 | 系统 / 固定 | 跟随系统 / 100% |

| Token | 舒适 | 紧凑 |
| --- | --- | --- |
| 卡片圆角 | 12（CardRadius） | 12 |
| 控件圆角 | 8（SM 6 / XS 4） | 8 |
| 列表行高 | 28 | 24 |
| 表格行高 | 30 | 26 |

切换即时生效并持久化；`ReduceTransparency` 强制实色/关闭系统材质，`HighContrast` 加强发丝线与对比。
Linux/Win10 没有系统材质：液态玻璃只剩半透明卡，界面会说明。

## 7. 玻璃与不透明度规则

**适合玻璃**：滚动内容上方的工具条、悬浮窗、命令面板、浮动工具条、液态玻璃预设下的工作卡、合并窗格。

**不适合**：连接/规则表格、日志、代码/ diff、长文本；透明根节点下没有任何已绘制内容的区域。设置块可以用卡片玻璃，内部控件只用洗色。

**约束**：

- 系统材质透的是桌面/其他窗口；窗口内玻璃只透应用自己画的内容。Linux/Win10 不写「桌面磨砂」。
- 一屏玻璃 pane ≤ 6；一个 `glass.Group` ≤ 8；嵌套玻璃最多两层。
- 工作卡不透明度是唯一入口：作用于 `CardFill`；不额外给控件加 alpha；0% 为完全透明。
- 卡片/侧栏上的控件只用洗色（见 `09-appearance.md` §5.1），禁止实心层色与禁用控件（见 §5.2）。
- 滚动内容从工具条下穿过用 `glass.ScrollEdge`；渐进模糊用 `glass.Blur`，不要手绘渐变。
- 低端机/远程桌面：预设切实色；不提供逐项模糊开关。

## 9. 页面规格

### 9.0 首次启动 `/welcome`

- 只在没有可用 Profile 时出现；三步：导入订阅 URL / 导入本地文件 / 跳过。
- 订阅导入显示名称可编辑、请求中骨架、失败可重试；成功后直接进入概览并提示「启用配置并开启系统代理」。
- 不在这里要求登录、不强制开启系统代理；跳过进入概览空状态。
- 键盘：默认焦点在 URL 输入；Enter 继续；Esc 不关闭，提供「稍后设置」。

### 9.1 概览 `/overview`

- 工具条：Profile 名（点击跳配置）、转发模式 `acrylic.SegmentedText`、系统代理/TUN 小开关、刷新状态。
- 第一行 4 张统计卡：实时上行（含 60s 曲线）、实时下行（含 60s 曲线）、活动连接数、内核运行时长/内存。
- 第二行：当前配置卡（订阅流量 `Meter`、到期日、更新按钮）、当前节点卡（组名、节点名、延迟、定位）。
- 底部：错误提示条（可展开详情、复制、关闭）与「上次更新」信息。
- 右上角：重启内核入口（确认后重启，恢复模式与选择）。
- 空状态：未导入配置时只显示引导卡（导入订阅 / 导入文件 / 从备份恢复）。
- 启动时若上次有 Profile，自动启用并启动内核；可在设置「常规」关闭自动启用。
- 数据源：`/traffic`、`/memory`、`/connections` 计数、`/configs`、`/proxies`；5s 轮询兜底。
- 快捷键：`Ctrl/Cmd+1` 进入本页。

### 9.2 代理 `/proxies`

- 工具条：搜索、排序（名称/延迟）、全部测速、视图（卡片/列表/简洁）、定位当前节点。
- 每组一张卡：组名、类型徽标、当前节点、延迟、组测速按钮、折叠；有图标时显示，无则首字母徽标。
- select 组：节点网格，点击即切换；当前节点高亮 + 勾选。
- url-test/fallback/load-balance：只读展示，标注「由内核管理」。
- 节点右键：测速、复制名称、复制代理地址、复制终端代理命令、查看详情（M2）。
- **网速测试**（M2）：节点行菜单「测网速」打开对话框，显示节点、将消耗流量、预计时长；
  实时显示下行/上行 Mbps、TTFB、已用流量与取消。指定节点仅 select 组可测，测完恢复原选择。
- 对话框底部：「测当前节点」「直连对照」「换一个测速地址」。
- 状态：测速中显示逐节点 spinner；失败显示错误徽标与 tooltip；无节点时说明「订阅未提供节点」。
- 快捷键：`/` 聚焦搜索、`T` 测当前组、`↑↓` 移动、`Enter` 选择。

### 9.3 配置 `/profiles`

- 工具条：添加订阅、导入文件、更新全部。
- 主区 `acrylic.Splitter`：左侧 Profile 列表（卡片），右侧详情（来源、更新时间、流量、覆写链状态、操作）。
- 卡片信息：名称、来源徽标（订阅/本地）、当前启用标记、更新时间、流量 `Meter`、到期日、更多菜单。
- 操作：启用（原子切换）、同步、编辑 YAML、编辑覆写、导出、复制、删除、拖拽排序。
- 来源区：编辑订阅 URL/请求头/间隔，或「取消关联」（保留已同步的 Profile）；删除 Profile 不自动删除订阅来源。
- 编辑器：`CodeEditor` + 底部校验条（行号、错误、保存/另存/还原）；离开未保存需确认。
- 保存当前启用 Profile 后自动重新应用；校验/应用失败时保留运行中配置，并提示回退。
- 更新全部：逐项进度，失败项保留旧内容并可重试。
- 自动同步（M2）：开关、间隔、启动时检查；失败项单独重试，不阻塞其他 Profile。
- 删除当前启用的 Profile 需二次确认：停核、清理 provider 目录、回到空状态；不自动切换。
- 空状态：见概览；本页也提供三个入口。

### 9.4 连接 `/connections`

- 工具条：搜索、暂停、关闭全部、导出。
- `Table` 列：主机、目的 IP、类型、网络、进程、规则、链路、上传、下载、时长。列支持拖拽调宽、排序、横向滚动；宽度/顺序/可见列持久化（M2 提供「列」菜单）。
- 排序：点击表头（时间/上传/下载）；过滤器与排序在内存中完成。
- 行选中打开右侧详情抽屉（M2）：完整 metadata、复制、关闭。
- 关闭全部需 `AlertDialog` 确认并显示当前条数。- 状态：无连接时插图 + 「当前没有活动连接」；暂停时顶部条提示「已暂停刷新」。

### 9.5 规则 `/rules`

- 工具条：搜索、类型筛选、每页条数。
- `acrylic.SegmentedText`：规则 / 规则提供者。
- 规则表：序号、类型、内容、策略、命中次数、最后命中（M2）、状态（禁用徽标）。
- 行菜单（M2）：临时禁用（重启后恢复）、复制内容；禁用行置灰并在页顶提示。
- 提供者表：名称、类型（http/file）、条目数、更新时间、操作（更新/预览）。
- 更新单条提供者显示行内进度；失败保留旧集并提示。
- 分页在客户端完成，搜索跨页。

### 9.6 日志 `/logs`

- 工具条：级别 `Select`、搜索、正则开关、暂停、清空、导出。
- 列表：时间（等宽）、级别色块、消息；长行折行，`Ctrl/Cmd+F` 打开 `FindBar`。
- 自动滚动开关；暂停时缓冲仍接收，恢复后补齐。
- 级别颜色：debug 灰、info 蓝、warning 黄、error 红。
- 导出为 `.log`，包含当前过滤条件说明。

### 9.7 网络组

**系统代理 `/sysproxy`（手动 M1；PAC M2）**

- 开关；代理方式 `acrylic.SegmentedText`（手动 / PAC，按平台能力显示）。
- 主机与端口（默认取 mixed-port）；绕过列表 `TokenField`，带平台语法校验与「恢复默认」。
- PAC：模板选择 + `CodeEditor` 预览/编辑 + 本机服务地址；默认模板为「私有网段直连，其余走代理」；不支持的桌面隐藏整块。
- UWP 工具（仅 Windows，M2）：列出/豁免回环应用；需管理员时引导提权。
- 开启/还原前比对系统当前值；被其他程序改过时提示「保留现状 / 还原快照」，不静默覆盖。
- 底部：原始系统设置备份（只读）与「还原」按钮。

**TUN `/tun`（M2）**

- 开关 + 权限状态（未授权/已授权/提权中）；失败时显示可执行建议。
- 参数：栈（system/gvisor/mixed）、网卡名、严格路由、自动路由、DNS 劫持、自动设置系统 DNS（默认 `1.1.1.1`/`8.8.8.8`）。
- 开启 TUN 时自动关闭系统代理并记住状态；关闭 TUN 时恢复，不弹二次询问。
- 诊断卡片：网卡存在、默认路由、DNS、权限、公网 IP（可关）、冲突（Windows Hyper-V/WSL、Linux docker0）逐项状态。
- 提权助手（M3）：安装/修复/卸载；显示版本与签名状态；失败给出可执行步骤。
- 修改参数需确认「将重启内核，连接会短暂中断」。

**DNS `/dns`**

- 页首提示：DNS 是应用级设置，保存后注入所有配置；「恢复为配置值」清除覆盖。
- 表单：启用 DNS 覆盖、监听地址、增强模式（Normal / Fake-IP）、Fake-IP 范围、`nameserver`、`fallback`。
- 多个地址用逗号或换行；保存会重启内核，并显示「当前生效」摘要。
- 清空缓存作为辅助操作，不做查询控制台；与参考产品保持一致。

**嗅探 `/sniffer`（M2）**

- 开关、协议（HTTP/TLS/QUIC）、端口列表、跳过/强制域名、按源/目标地址跳过。
- 底部：「仅保存」与「保存并重载」。

### 9.8 工具组

**覆写 `/override`**

- Profile 选择器；`acrylic.SegmentedText`：合并（M1）/ 脚本（M2）/ 预览（M2）。
- 合并：`CodeEditor`（YAML）+ 语法校验 + 模板插入 + 重置为默认。
- 脚本（M2）：`CodeEditor`（JS）+ 运行日志 + 超时说明。
- 预览（M2）：三段只读（Base / Merge / Runtime），`DiffViewer` 对比；可复制。

**资源 `/resources`**

- 代理提供者表（M1，与规则页组件一致）：更新全部、健康检查、条目数、更新时间。
- Geo 状态卡（M2）：文件、版本/时间、大小、更新按钮、校验失败提示。
- Web 面板资源（M2）：已安装版本、可用更新、下载/校验/删除。

**内核 `/core`**

- 概览卡：mihomo 版本、路径、启动时间、当前宿主（GUI/Agent/Privileged）、转发模式。
- 操作：重启内核、打开日志、复制诊断信息、检查应用更新（内核随应用）。
- 没有独立内核下载/切换入口；更新说明写「随应用更新」。
- 重启前确认「连接会短暂中断」；TUN 开启时先停 TUN。

**流量 `/traffic`（M3）**

- 时间范围（今日/本周/本月/自定义）+ 上行/下行柱状图（`chart`）。
- 汇总卡：总量、峰值速率、按 Profile 拆分表。
- 空状态：说明「从启用后开始统计」。

**解锁 `/unlock`（M3）**

- 目标列表（可编辑）+ 「开始检测」；逐项状态（检测中/可用/仅自制/IP 受限/失败）。
- 结果表：服务、状态、地区、耗时、当前节点；导出 JSON/CSV。

**面板 `/panel`**

- `ui.WebView` 全区域 + 顶部工具条（刷新、在浏览器打开、复制地址）。
- 连接信息按面板支持的 URL 参数格式传入（如 `hostname`/`port`/`secret`），仅内置本地面板；自定义远程面板默认不附带 secret，并显示风险提示。
- 未下载资源时显示说明与「下载面板」；缺 WebView2/WebKitGTK 时给出安装指引。

### 9.9 设置 `/settings`

- 左侧二级导航（常规、外观、内核、高级内核、托盘、热键、更新、数据、关于），右侧滚动表单；不用 9 个 Tab。外观含材质（液态玻璃/透明/实色）、工作卡不透明度 0–100%、密度、明暗与界面缩放 100–125%。
- 常规：开机启动、静默启动、关闭窗口行为（托盘/退出）、语言、自动启用上次 Profile。
- 托盘：菜单项、动态速率、点击行为；与 Agent/轻量模式归属说明。
- 热键：显示窗口、切转发模式、系统代理、TUN；冲突时标红并给出可用组合。
- 高级内核（M2）：unified-delay、tcp-concurrent、find-process-mode、fingerprint、interface-name、routing-mark；“恢复默认”。
- 常规含「轻量模式」（M3）：关闭窗口后释放界面内存，保留托盘与内核；开启前说明代价与模式切换会断流。
- 内核含端口、日志级别、Controller 端口/secret；详细状态与重启在 `/core` 页；高级内核项（M2）见下一节。
- 数据页：打开目录、备份/恢复、WebDAV（M3）、诊断包导出、重置、便携模式状态（只读）。
- 每项即改即存，危险操作（重置、删除数据）二次确认并显示影响范围。
- 更新页显示当前版本、渠道、检查结果、下载进度与「查看发布说明」。
- 关于页：版本、许可（GPL-3.0）、第三方声明、源码与问题反馈链接。

## 10. 托盘、悬浮窗、命令面板与通知

### 10.1 托盘

- 菜单：显示窗口、转发模式（规则/全局/直连）、系统代理、TUN、重启内核、当前配置、测速、退出。
- 交互：Windows/macOS 左键打开主窗口、右键弹出原生菜单（菜单临时挂载，关闭后卸下）；
  Linux AppIndicator 只支持菜单，点击弹出菜单，首项为「显示窗口」。
- 动态速率：macOS 用 `SetTitle` 文本（等宽数字，用 U+2007 补齐位宽），Windows/Linux 绘制到图标；
  模板图标随明暗自动着色；节流 1s。
- 轻量模式下托盘由 Agent 拥有；窗口打开时状态条显示「内核在后台」。

### 10.2 悬浮窗

- 默认 180×64，无边框、置顶、整窗一张 Card；可选系统材质/玻璃；只显示上/下行速率与连接数。
- 拖拽移动，位置与显示器归属记忆；越界时夹回可见区域。
- 双击打开主窗口；右键菜单与托盘一致（精简版）。
- 「锁定」时点击穿透；平台不支持时隐藏该选项并说明。
- 刷新 1s；失焦降频；不抢焦点。

### 10.3 命令面板 `Ctrl/Cmd+K`

- 实色 Modal + `acrylic.SearchField` + `acrylic.Row`；打开即聚焦，Esc 关闭。
- 结果分组：页面（概览/代理/配置/…）、操作（切转发模式/开关系统代理/重启内核/检查更新）、
  节点（搜索代理组内的节点）、配置（切换 Profile）。
- 键盘：↑↓ 移动、Enter 执行、Tab 切分组；无结果时说明可搜索的内容。
- 动作不可用时显示原因（如「内核未运行」），不静默隐藏；危险动作需确认。
- 最近使用最多 5 条，仅本次会话；不记录搜索历史。

### 10.4 通知

- 只用于「窗口不在前台」的结果：更新完成、订阅同步失败、内核异常重启。
- 窗口内的结果一律 `c.Toast`；同类通知合并，避免刷屏。
- 可在设置中关闭；macOS 首次使用请求权限，拒绝后只留窗口内提示。

## 11. 键盘与无障碍

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl/Cmd+1..6` | 概览/代理/配置/连接/规则/日志 |
| `Ctrl/Cmd+B` | 折叠侧栏 |
| `Ctrl/Cmd+F` | 当前页搜索 |
| `Ctrl/Cmd+,` | 设置 |
| `Ctrl/Cmd+R` | 刷新当前页数据（不重载配置） |
| `Space` | 日志/连接暂停切换 |
| `Esc` | 关闭抽屉/对话框 |
| `Ctrl/Cmd+K` | 命令面板：跳页、切转发模式、选节点、开设置、重启内核 |
| `Ctrl/Cmd+U` | 检查更新 |

- 所有图标按钮必须有 `Label`；表格列头可键盘排序。
- 焦点顺序与视觉顺序一致；抽屉打开后焦点进入抽屉，关闭后回到触发元素。
- 颜色不是唯一信息载体：延迟同时显示数值与色块；状态同时显示文本。
- 屏幕阅读器依赖真实控件语义，不用 `Box` 模拟按钮。

## 12. 文案与 i18n

- 所有字符串走 `i18n`，key 采用 `区域.对象.动作`：`profiles.action.updateAll`、`errors.portInUse`。
- 不在代码里拼接句子；占位符用命名参数，英文复数单独处理。
- 术语严格按 `GLOSSARY.md`：Profile 不译「配置文件」，Subscription 不译「机场」。
- 错误文案三段式：发生了什么、为什么、下一步动作（可点击）。
- 中英同批提交；缺键在开发构建中直接显示 key，CI 检查缺键。
