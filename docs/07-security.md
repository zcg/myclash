# 安全与威胁模型

> 范围：本机桌面应用。攻击者假设为「同用户的其他进程」「本地网络中的设备」「恶意订阅/面板/更新源」。
> 不同用户之间的隔离、内核提权漏洞利用链不在本文范围（依赖操作系统与 mihomo）。

## 1. 资产

| 资产 | 位置 | 泄露后果 |
| --- | --- | --- |
| Subscription URL / Authorization | `profiles.yaml`、系统密钥库 | 订阅被他人使用、流量被消耗 |
| Controller secret | 内存；生成后不落盘 | 本机进程可读状态、切节点 |
| WebDAV 凭据 | 系统密钥库 | 远端备份被读取/覆盖 |
| Runtime Config | 内存；落盘版本脱敏 | 暴露节点与规则（低敏） |
| 提权内核进程 | TUN 期间存在 | 若被利用可获管理员权限 |
| 更新通道 | GitHub Releases | 供应链投毒 |

## 2. 信任边界

```
[订阅服务器] --HTTPS--> [GUI]
[更新源]     --HTTPS--> [updater] --验签--> [安装]
[WebView 面板] --loopback REST--> [Core]
[GUI] --stdin 管道--> [Privileged Core (root)]
[本机其他进程] --?--> [Controller / 数据文件]
```

- GUI 以普通用户运行；只有 Privileged Core 提权，权限仅够建网卡/改路由/DNS。
- Controller 只绑 `127.0.0.1`，强制 secret；不提供 TLS/远程监听。
- 面板是唯一被允许执行第三方 Web 内容的地方；它拿到的权限受 URL 参数限制。

## 3. 威胁与对策

### T1 本机进程读取 secret 或订阅凭据

- Runtime Config 落盘前把 `secret` 替换为 `<redacted>`；内核启动用内存中的真实值。
- 订阅 URL 中的 token 视为敏感：`profiles.yaml` 权限 0600（Windows 用当前用户 ACL）；诊断包脱敏。
- WebDAV/Authorization 进系统密钥库，不进 YAML。
- 本地备份与 WebDAV 备份包含订阅 URL，属于敏感数据：备份文件权限 0600；上传前明示，不自动上传；不提供公开分享链接。

### T2 提权内核被伪造配置利用（TOCTOU / 路径注入）

- 配置与命令只走 stdin，不写临时文件、不进 argv。
- 子进程校验：父进程存在、`parent_exe` 与 `os.Executable()` 一致、一次性 token 长度/来源合法。
- 配置大小上限（64MB）；解析失败即退出，不执行任何外部路径。
- 子进程只接受四种命令：reload、set-mode、update-geo、stop；无 shell、无文件读写接口。

### T3 WebView 面板窃取 secret

- 默认面板必须是本地资源（`cache/panel`），经 URL 参数注入 `hostname/port/secret`。
- 自定义远程面板默认**不注入 secret**，并在打开前显示风险说明；用户显式勾选后才注入。
- 面板窗口禁用开发者工具（发布构建）、禁止导航到非 http(s) 协议；关闭时清空会话数据。

### T4 恶意订阅

- 只接受 YAML 映射；拒绝多文档、超大文件（>32MB）、超深嵌套与超量别名（防 billion laughs）。
- Provider 路径统一重写到 `<userData>/core/providers/<profileUID>/` 下；拒绝绝对路径、`..`、盘符与 UNC。
- 订阅内容中的脚本/命令字段一律不执行；只作为字符串保留。
- 规则/代理条目数上限（可配，默认 100k/50k），超限拒绝应用并提示。

### T5 更新供应链

- 资产必须由 `mygo keygen` 私钥签名；客户端内置公钥，验签失败拒绝安装。
- 拒绝降级：版本号必须大于当前版本；资产名与 tag 前缀匹配。
- 更新前停止 TUN 与系统代理；失败保留旧版本并可回滚。

### T6 PAC / 代理服务被本地滥用

- PAC 服务器只绑 `127.0.0.1`，随机端口 + 一次性 token 路径，只响应 GET；不提供目录浏览。
- 系统代理只写当前用户设置（Windows HKCU），不需要管理员。
- 开启 `allow-lan` 需二次确认；默认关闭；不做未经认证的公开监听。

### T7 脚本覆写逃逸

- goja 运行时不注入 `os`/`net`/`fs`/`require`；只暴露纯计算与 `console.log`。
- 2s 超时（中断），返回值必须是对象；失败不落盘、不切换。
- 不缓存执行结果；每次生成都重跑。

### T8 本地数据被替换（符号链接/目录穿越）

- 所有路径由应用拼接后在 `<userData>` 内校验；拒绝 `..` 与绝对路径。
- 便携模式的 `data/` 目录同样校验；不跟随指向目录外的符号链接。
- 写入统一「临时文件 + rename」，临时文件与目标同目录。

### T9 提权助手被卸载/残留

- 安装/卸载脚本幂等；卸载时移除服务、LaunchDaemon、polkit 规则、开机启动与 TUN 网卡。
- 助手升级需签名一致；版本不匹配时拒绝启动并提示重装。

### T10 崩溃导致断网或 DNS 残留

- 启动自检：系统代理残留 → 按快照恢复；TUN 标记残留 → 清理网卡、恢复 DNS。
- `--no-proxy` 安全模式只做修复，不启动代理。
- PAC 服务随应用退出；系统代理在退出钩子中优先关闭。

### T11 日志/诊断泄露

- 导出前替换：订阅 URL、Authorization、secret、WebDAV 用户名、节点密码。
- 诊断包列出「已脱敏字段」清单；默认不含完整配置，只含结构与错误。
- 应用日志默认保留 7 天、单文件 8MB；设置 → 数据可改为永久/1/7/30 天与 1–1024MB，达到容量即清空。

### T12 代理环路

- 订阅、更新、Geo、WebDAV 请求的 `http.Client` 显式 `Proxy: nil`，避免走系统代理。
- 系统代理绕过列表强制包含 `127.*`、`<local>` 与本机监听地址。
- PAC 脚本不引用自身地址。

### T13 Agent 控制通道被本机滥用

- socket/管道只在 `<userData>`，权限 0600；token 每次启动生成。
- 只接受 JSON Lines 白名单方法；单条 30s 超时；协议版本不匹配即拒绝。
- 不监听 TCP；不提供文件读写/命令执行接口；控制方法白名单固定。
- GUI 附着前校验 token 与协议，失败不降级为「无鉴权」。

### T14 测速端点被用作探测工具

- 只允许 `http(s)`；默认拒绝回环与内网地址。
- 用户改为内网地址时二次确认；不自动扫描端口，只做单次 GET/POST。
- 测速结果不上传；端点可替换但不接受重定向到非 http(s)。

## 4. 安全默认值

| 项 | 默认 |
| --- | --- |
| Controller 绑定 | `127.0.0.1` |
| allow-lan | 关闭 |
| IPv6 | 关闭 |
| 系统代理 | 关闭 |
| TUN | 关闭 |
| Web 面板 secret 注入 | 仅内置本地面板 |
| 自定义远程面板 | 不支持 secret，需确认 |
| 遥测 | 无 |
| 更新 | 验签，拒绝降级；内核随应用更新 |
| Agent 控制通道 | 本地 socket，0600 + token |
| 订阅内容脚本 | 不执行 |
| 测速端点 | 默认拒绝内网/回环 |

## 5. 验收测试（安全）

- [ ] 落盘的 `runtime/*.yaml` 中搜索不到 controller secret。
- [ ] 伪造 `--core` 子进程调用：父进程不匹配 / token 错误 / 超长配置，均拒绝启动。
- [ ] 订阅含 `path: ../../etc/passwd` 时被拒绝，且不写任何文件到目录外。
- [ ] 面板导航到 `file://` 或外部站点时被阻止；远程面板无 secret。
- [ ] 更新资产替换/删除签名后安装被拒绝。
- [ ] 模拟崩溃后重启，系统代理与 DNS 恢复；`--no-proxy` 不触碰系统设置。
- [ ] 诊断包中订阅 URL 与 token 全部为 `<redacted>`。
- [ ] 伪造的 Agent 附着（错 token/旧协议）被拒绝。
- [ ] 测速端点填内网地址时需确认；填 `file://` 被拒绝。
